# 🚀 그냥퀵위젯(GN QuickWidget) 사용 설명서

**그냥퀵위젯**은 효율적인 작업 환경을 위해 디자인된 **퀵위젯바**와 상세 설정을 위한 **설정창**으로 구성되어 있습니다.

---

## 1. 기본 사용법

### 1.1 퀵위젯바 레이아웃 및 기본 조작
* **구성 요소 (좌측부터):**
    * `이동핸들`, `설정 아이콘(톱니바퀴)`, `자석 활성/해제`, `위젯바 축소/확장`, `수동 회전 아이콘`(자석 비활성 시 노출)
* **이동 방법:** 이동핸들뿐만 아니라 **위젯바의 빈 공간을 클릭 후 드래그**하여 자유롭게 이동할 수 있습니다.
* **페이징 시스템:** 
    * 3페이지 이하일 때는 **점**으로 표시, 3페이지 이상일 때는 **숫자**로 표시됩니다.
    * 회원 등급에 따라 사용 가능한 페이지 수가 고정됩니다.
* **실행 슬롯:** 기본 10개x3페이지의 슬롯을 제공하며, 비회원일 경우 `+1` 형태의 **AD(광고) 슬롯**이 노출됩니다.
* **페이지 전환:** 위젯바 위에서 **마우스 휠**을 돌리거나 **페이징 아이콘(점 또는 숫자)**을 클릭하여 전환합니다.
* **크기 조절:** `Ctrl` + `마우스 휠`을 이용하여 위젯바의 크기를 실시간으로 조절할 수 있습니다.
* **동작 실행 및 관리:**
    * **실행:** 등록된 버튼을 클릭하여 정의된 동작을 실행합니다.
    * **편집:** 우클릭 시 수정 및 삭제가 가능합니다.
    * **순서 변경:** 클릭 후 드래그하여 버튼의 위치를 이동할 수 있습니다.
* **동작 제한 및 중단:**
    * 하나의 버튼 동작이 끝날 때까지는 다른 버튼을 실행할 수 없습니다.
    * 의도치 않게 동작이 꼬인 경우 `Shift` + `Esc` 키로 **동작을 강제로 중단**할 수 있습니다. (보통은 사용할 일이 없으나, 긴 매크로 실행 시 끝까지 기다리지 않고 중단할 때 유용합니다.)

### 1.2 슬롯 상태 및 아이콘 안내
* **AD 슬롯:** 비회원 시 노출되며 수정/삭제가 불가능합니다. (무료 회원 등록만으로 제거 가능)
* **매크로 버튼:** 버튼 좌측 상단에 **매크로 미니 아이콘**이 표시됩니다.
* **예약 기능:** 해당 버튼에 예약 기능 사용 시 우측 상단에 **타이머 미니 아이콘**이 표시됩니다.
* **단축키 표시:** 설정창에서 기능을 활성화하면 버튼 하단에 등록된 **단축키**가 표시됩니다.

### 1.3 회원 등급 및 서비스 안내
* **체험 서비스:** 설치 후 회원 등록 없이 **15일간** 제공 (슬롯 3페이지 기본 제공)
* **무료 회원:** 등록 시 일부 서비스 제한이 있으나 **기간 제한 없이** 사용 가능 (슬롯 3페이지 기본 제공)
* **유료 회원:** 서비스 제한 없이 모든 기능 사용 가능 (슬롯 5페이지 제공, **현재 유료 회원 등록은 불가합니다!**)

## 2. 설정창 상세 안내

설정창은 퀵위젯바의 **톱니바퀴 아이콘**을 통해 진입하거나 기타 지정된 방법으로 접근 가능합니다.

### 2.1 설정창 레이아웃 구성
* **상단바:** 사용자 정보(미가입, 무료, 유료), 로그인/로그아웃, 유료 전환 및 기간 연장 버튼 노출
* **좌측 메뉴:** `버튼배치관리`, `버튼편집`, `위젯기본설정`
* **메인 화면:** 각 메뉴에 대응하는 설정 화면 노출
* **하단 영역:** 위젯 버전 정보 표시 (클릭 시 개발자 깃허브로 연결되어 업데이트 내용 확인 가능)

### 2.2 설정창 메뉴별 상세 설명

#### 📁 위젯 기본 설정
1. **크기 조절:** 선택 박스를 통해 조절 (위젯바에서 직접 `Ctrl` + 휠 조절도 가능)
2. **투명도:** 슬라이드 바를 통해 위젯바 투명도 조절
3. **즉시 호출:** 위젯 위치와 상관없이 메인 모니터 중앙으로 호출하는 **단축키 등록** 기능
4. **기능 옵션:** 위젯바에서 제공하는 각종 기능의 활성화/비활성화 설정
5. **백업 및 복원:** 모든 데이터는 로컬 PC에 저장되며, 전체 데이터의 백업 및 복구 지원
6. **스마트폰 연동:** PC로 인증번호 문자를 전송하여 스마트폰 인증번호를 PC에서 즉시 사용 가능 (현재 인증번호 서비스만 제공)

#### 📝 버튼 편집 (기능 및 워크플로우)
* **빠른 등록:** 바탕화면 바로가기, 폴더, 실행 파일을 드래그 앤 드랍하여 기본 정보 및 동작을 즉시 설정 가능
* **수동 등록:** 사용자가 직접 정보를 입력하여 등록 가능
* **기능 유형별 설정:**
    * **파일/폴더/프로그램 열기:** 실행 경로 지정 및 저장
    * **웹사이트(URL):** 브라우저 사용 관련 추가 옵션 제공
    * **그냥 워크플로우(자동화 루틴):**
        * **실행 타겟:** 현재 PC에서 실행 중인 프로그램을 선택하여 지정 가능
        * **동작 구성:** 자동화 동작 공간을 통해 단순 매크로 작성 가능
        * **편집:** 동작 블록 추가/삭제 및 드래그 앤 드랍으로 순서 변경
* **동작 블록 옵션 상세:**
    * `텍스트 입력`: 미리 설정한 텍스트 입력이 필요할 때 사용
    * `키 입력(조합키)`: 특수키와 조합할 키 등록
    * `일반 대기`: 블록 사이 지연 시간 수동 등록 (예: 500 = 0.5초)
    * `스마트 대기`: 일반 대기보다 효율적인 대기 시간 관리 (베타 기간 제한 없음, 작동이 원활하지 않을 경우 일반 대기로 대체 권장)
    * `시스템 제어`: 윈도우 키 조합 등 미리 생성된 단축키 선택 사용
    * `프로그램 실행`: 경로 입력 실행 또는 이미 실행 중인 프로그램 선택 실행
    * `미디어 제어`: 볼륨, 재생 등 미리 등록된 미디어 단축키 사용
    * `마우스 좌표 이동`: 캡처 버튼 클릭 후 원하는 위치에서 **F8**을 눌러 좌표 등록 (이동 후 클릭, 더블클릭 등 후속 동작 선택 가능)
    * `이미지 서치 이동`: 특정 화면을 이미지로 캡처하여 해당 이미지를 찾아 커서 이동 (좌표 이동과 동일한 후속 동작 지원)
    * `마우스 클릭/드래그`: 마우스 키 입력 지정
* **기타 블록 기능:**
    * **블록 반복:** 각 블록의 동작 반복 횟수 지정 (예: 탭 키 5번 필요 시 반복 횟수 5로 지정)
    * **워크플로우 반복:** 전체 루틴의 반복 실행 횟수 지정 (기본 1회)
* **스케줄 설정:**
    * 특정 요일 및 시간에 **자동 실행** 기능 제공 (예약 실행을 위해 PC와 위젯이 켜져 있어야 함)
    * 설정 시간과 실제 실행 시간 사이에는 수 초 내외의 오차가 있을 수 있음
* **공유 및 저장:**
    * **복사/붙여넣기:** 버튼 설정을 JSON 구조로 클립보드에 복사하여 다른 사용자와 공유 가능
    * **저장:** 편집 후 반드시 하단의 **저장 버튼**을 눌러야 적용됩니다. (**저장 안 하면....**)

#### 📊 버튼 배치 관리
* 퀵위젯바 슬롯 현황을 한눈에 파악하고 편집/수정 가능
* 등록된 버튼의 순서를 드래그하여 페이지 간 이동 가능
* **보관함:** 자주 사용하지 않는 버튼을 드래그하여 무제한 보관 가능 (위젯바에는 노출되지 않으나 삭제되지 않으며, **예약 설정된 버튼은 보관함에 있어도 정상 동작**함)

## 3. 퀵위젯바 슬롯 등록/수정/삭제 방법

실행 버튼을 등록하는 방법은 다음 3가지가 있습니다.
1. 바탕화면/폴더의 아이콘을 위젯바 빈 슬롯에 **드래그 앤 드랍**
2. 퀵위젯바의 **빈 슬롯을 직접 클릭**하여 시작
3. 설정창의 **'버튼 배치 관리'** 화면에서 빈 슬롯을 클릭하여 시작

사용자의 특정 소프트웨어 환경에 따라 개발자의 의도와 다르게 기능 간 간섭이나 예외 처리 미흡으로 인한 버그가 발생할 수 있습니다. 충분한 테스트를 거쳐 업데이트를 진행하고 있으나, 정상 구현된 기능이 작동하지 않을 수 있음을 양해 부탁드립니다. 😭
